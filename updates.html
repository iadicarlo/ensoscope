What's new

What has been added, changed or fixed on ENSOscope, most recent first. New to the platform? Start with the Guide.

ENSOscope is updated monthly with the new forecast, and between those updates whenever a layer is added or a problem is found. Much of what is listed here comes from questions and feedback sent by the humanitarian teams using it, which is the fastest way to get something fixed or added.

How to read the tags

  • New data a new indicator or dataset you can now map.
  • New feature a new page or tool on the site.
  • Fix something that was wrong and has been corrected.
  • Forecast update the routine monthly refresh of the forecast.

Methods behind each indicator are documented on the Methodology and data page. To report a problem or request an indicator, see About and contact.
